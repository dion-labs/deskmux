## Reproduction and acceptance receipt

Baseline: `swift test --scratch-path .build/public-preview` (wrap with the coordinated resource-run.py for this burn). Filtered suites use `--filter` plus test-name regex. Record date, Git revision and dirty diff, command, exit status, test count and raw log. All newly added cases require a fresh run regardless of baseline age.

Manual receipt per ID: date; app version/build and both Mac/OS models; disposable fixtures; preconditions/permissions; exact actions; expected and observed result; screenshots or sanitized logs; recovery action; PASS/FAIL/BLOCKED. DDC readback and visible image are separate observations. No unit test can certify MacBook switching or window opening after restart. Stop on lost local control, unexpected personal data access, or ambiguous device identity.
