# Mux / DeskMux identity

Mux is an original twin-tailed lynx: ivory, teal and warm orange. The two tails
represent the two sides of a shared desk. The small monochrome menu mark uses
the ears as an M and two eyes as a pair of Macs; the full character is reserved
for the app icon and presentation site.

Palette: paper `#f4f1e9`, ink `#172e2c`, teal `#357d77`, coral `#e66b48`.
Typography: native system fonts in the app; Manrope and DM Sans on the site.

`mux.png` is the original transparent raster master. It was generated using
the built-in image generation tool, with this brief:

> Original DeskMux mascot: an elegant ivory twin-tailed lynx with charcoal ear
> tips, teal eyes, one warm orange and one teal tail tip, seated in a confident
> three-quarter pose with a raised paw. Premium Japanese designer collectible
> and editorial character treatment, controlled soft lighting, transparent
> square canvas, no words or logos.

The SVG/SwiftUI menu mark is drawn separately for small-size legibility.
Generated artwork is distributed with DeskMux under its MIT license.
